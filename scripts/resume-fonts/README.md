# Resume fonts

Vazirmatn Regular and Bold come from the [official Vazirmatn project](https://github.com/rastikerdar/vazirmatn/tree/master/fonts/ttf). The SIL Open Font License is included in `OFL.txt`.

The Word exporter loads these fonts for the export session, embeds them in the Persian Word/PDF outputs, and releases the session font registrations when finished. It does not install them permanently.
