# Mehrad Yaghoubi — personal portfolio

A bilingual, 3D portfolio for research in visual speech recognition and computer vision.

## Run locally

```sh
npm install
npm run dev
```

## Publish on GitHub Pages

Create a public repository named `mehradyaghoubi.github.io`, add these files, and push the `main` branch. In **Settings → Pages**, choose **GitHub Actions** as the publishing source. The included workflow builds and deploys the site on every push to `main`.

The website URL is `https://mehradyaghoubi.github.io/`.
